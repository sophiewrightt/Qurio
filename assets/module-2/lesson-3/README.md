# Lesson 3 artwork

These assets are screen-sized crops and transparent cutouts of Sophie Wright's supplied Qurio drawings. The crop windows keep the original crayon marks unchanged while removing the large white scan margins so the artwork can be centred responsively in the lesson UI.

The rainbow-basketball and photoelectric-effect cutouts were background-extracted with the built-in image editor. The continuous-level diagram uses a lossless colour-key cutout so its handwritten `level = ∞` label remains exact. The blowtorch and element PNGs use the same lossless process, allowing the flame-test interactive to sit directly on the lesson background without white rectangles.
